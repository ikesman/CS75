# ============================================
#  AutoKit 闪退修复 — 使用指南
# ============================================
# 
# 车机：长安CS75 / Android 4.4.2 / Quick Boot
# APP：AutoKit 2022.11.15.1535
# 固件：2022.12.08
#
# 问题：每次熄火后重新上车，点击AutoKit闪退
# 原因：Quick Boot休眠唤醒后APP的缓存数据损坏

========================================
  方案A：一键启动脚本（最简单）
========================================

原理：每次启动前自动清除损坏数据，再打开APP

步骤：
  1. 将 quick_start.sh 复制到U盘
  2. U盘插车机，用RE管理器将文件复制到 /sdcard/
  3. 以后每次上车，不要点AutoKit图标
     而是打开RE管理器 → /sdcard/quick_start.sh → 以脚本方式执行
  4. 等3秒APP自动打开，正常使用CarPlay

优点：零风险，不改系统，随时可停用
缺点：每次需要手动点一下RE执行脚本

提升体验：
  如果车机装有 "脚本管理器(SManager)" 或 "终端模拟器" 类应用，
  可以为脚本创建桌面快捷方式，等同于一键启动。


========================================
  方案B：安装为系统应用（推荐）
========================================

原理：系统应用享有更高优先级，崩溃后可被系统自动重启，
      且DEX优化在安装时一次性完成，不会被Quick Boot破坏

前提：需要Root权限（能用RE管理器访问/system/说明有Root）

步骤：
  1. 将以下文件复制到U盘：
     - AutoKit_2022.11.15.1535.apk
     - install_as_system_app.sh
  2. U盘插车机，用RE管理器将两个文件复制到 /sdcard/
  3. 用RE管理器打开 /sdcard/install_as_system_app.sh，以脚本方式执行
  4. 等待执行完毕，看到"完成"提示
  5. 重启车机（需要完整重启，不是Quick Boot）
     方法：断开电瓶正极等待30秒后重新连接
  6. 重启后AutoKit会作为系统应用自动优化和运行

验证：
  打开 设置 → 应用 → AutoKit，如果显示"系统应用"标签则成功

如果需要恢复：
  用RE管理器删除 /system/priv-app/AutoKit.apk，重启


========================================
  方案C：后台守护（全自动）
========================================

原理：安装一个后台守护进程，持续监控AutoKit状态，
      唤醒或闪退时自动修复重启

前提：需要Root权限

步骤：
  1. 将以下文件复制到U盘：
     - autokit_guard.sh
     - install_guard.sh
  2. U盘插车机，用RE管理器将两个文件复制到 /sdcard/
  3. 用RE管理器打开 /sdcard/install_guard.sh，以Root执行
  4. 看到"安装完成"提示后即可

效果：
  - 开机自动启动守护进程
  - Quick Boot唤醒后 ~20秒内自动修复启动AutoKit
  - APP闪退后自动重启（最多3次）
  - 完全无需手动操作

如果需要卸载：
  用RE管理器删除：
    /data/local/tmp/autokit_guard.sh
    /system/etc/install-recovery.sh（执行前先 mount -o rw,remount /system）


========================================
  推荐执行顺序
========================================

1. 先试方案A（零风险验证原理是否有效）
   → 如果quick_start.sh能稳定启动APP，说明"清数据+重启"方案有效

2. 确认有效后，上方案B（安装为系统应用）
   → 这可能直接根治问题

3. 如果方案B仍然闪退，叠加方案C（守护进程）
   → 方案B + C 组合 = 系统应用 + 自动监控修复

4. 如果没有Root权限，只能使用方案A
   → 建议安装一个脚本快捷方式工具简化操作


========================================
  ADB远程操作方法（备用）
========================================

如果你有笔记本电脑，可以通过WiFi连接车机ADB执行修复：

  # 连接车机（需要和车机在同一WiFi，或车机IP）
  adb connect 车机IP:5555
  
  # 执行修复
  adb shell am force-stop cn.manstep.phonemirrorBox
  adb shell pm clear cn.manstep.phonemirrorBox
  adb shell am start -n cn.manstep.phonemirrorBox/.CheckActivity
