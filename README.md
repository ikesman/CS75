# CS75 车机指南

面向 GitHub Pages 的静态教程站：把 CS75 的系统降级、工程模式、文件管理器、第三方应用和车易联 CarPlay 稳定方案整理为可按步骤操作的路线。

## 页面内容

- **选包判断器**：按年款和目标生成第一步清单。
- **U 盘摆放图**：明确区分 `update.zip`、普通 APK、AutoKit 修复脚本的放置方式。
- **降级与工程模式**：基于仓库内《2018 款 CS75 车机自行安装 APP 操作说明》逐步整理。
- **CarPlay**：从零改动的一键启动到 v4 自动修复的分级方案，并说明冷启动验证标准。
- **资源索引**：每个链接写明用途、风险和放置位置。

## GitHub 发布结构

仓库内的固件总量约 8 GB，多个单文件超过 GitHub 普通仓库的 100 MB 限制。因此 Pages 源码会忽略大型 `.zip`、`.rar`、`.img` 与绝大多数 APK。系统固件、语音资源、盒子固件在页面中统一引导至闲鱼搜索 **ikesman** 获取；教程仍会明确说明对应年款、文件名和 U 盘放置方式。

## 本地预览

直接打开 `index.html`，或执行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 发布前注意

- 保持资源目录和文件名不变，页面链接依赖当前相对路径。
- 系统包的 `update.zip` **不解压**，一次只使用一个目标包。
- 盒子固件、Root 与系统修复操作都有风险；确认车型、主机和盒子型号后再进行。
