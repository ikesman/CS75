============================================
  AutoKit 终极修复 v4 - 使用说明
============================================

【背景】
  WiFi ADB连不上车机（端口5555未监听），
  因此使用车机上的RE管理器+Root直接执行修复。

  v4方案改进：
  - 比v3增加了开机自动修复脚本
  - 开机脚本放在/system/bin/（比/data更可靠）
  - 多层保护：系统应用 + 白名单 + 开机自修复
  - 完整的日志输出便于排查

【文件清单】
  enable_wifi_adb.sh  - WiFi ADB启用工具（备用）
  1_diagnose_v4.sh    - 深度诊断（先运行此脚本）
  2_fix_v4.sh         - 一键修复（核心脚本）
  3_uninstall_v4.sh   - 卸载恢复

============================================
  操作步骤
============================================

准备：
  1. 将以下文件复制到U盘：
     - 1_diagnose_v4.sh
     - 2_fix_v4.sh
     - 3_uninstall_v4.sh
     - AutoKit_2022.11.15.1535.apk（从"车机软件包"中获取）
  2. U盘插入车机
  3. 用RE管理器将所有文件复制到 /sdcard/ 根目录

第一步：运行诊断
  1. RE管理器 → /sdcard/1_diagnose_v4.sh → 以Root执行
  2. 等待运行完毕
  3. 日志自动保存到 /sdcard/autokit_diag.log
  4. 可以先把日志复制到U盘带回电脑分析

第二步：运行修复
  1. 确保 /sdcard/ 下有 AutoKit_2022.11.15.1535.apk
  2. RE管理器 → /sdcard/2_fix_v4.sh → 以Root执行
  3. 等待看到"修复完成"
  4. AutoKit应该会自动启动

第三步：冷启动测试（关键！）
  1. 完全断电（断电瓶正极30秒以上）
  2. 重新通电启动车机
  3. 等待20-30秒，观察AutoKit是否自动启动
  4. 如果没自动启动，手动点击图标看是否能打开
  5. 重复断电-启动测试3次

测试结果：
  ✓ 3次都能打开 → 修复成功！
  ✗ 仍不行 → 把以下日志文件带回电脑：
    /sdcard/autokit_diag.log
    /sdcard/autokit_fix_v4.log
    /data/local/tmp/autokit_boot.log

如需恢复原状：
  RE管理器执行 /sdcard/3_uninstall_v4.sh

============================================
  v4 修复原理
============================================

Layer 1 - 系统应用:
  将AutoKit安装到/system/priv-app/，系统应用的
  dalvik缓存管理比普通应用更可靠，不会被清理。

Layer 2 - 白名单保护:
  加入bootwhitelist.txt，车机系统会保护白名单
  中应用的缓存和数据不被启动清理流程清除。

Layer 3 - 开机自修复:
  在/system/bin/安装开机脚本，通过install-recovery.sh
  触发。每次开机自动检查AutoKit状态，如果发现异常
  则自动清缓存+重装+启动。

Layer 4 - 日志追踪:
  每次开机修复的详细日志写入/data/local/tmp/autokit_boot.log
  用于排查问题。
