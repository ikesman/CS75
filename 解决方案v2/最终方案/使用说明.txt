====================================
 AutoKit 闪退终极修复 - 使用说明
====================================

【问题根因】
  你的车机用的是 Dalvik 虚拟机（Android 4.4.2）。
  每次安装APP时，系统会把APK中的代码优化成ODEX缓存文件，
  存放在 /data/dalvik-cache/ 目录下。
  
  车机彻底断电后，这个ODEX缓存文件损坏了（断电时可能
  正在写入），导致下次启动时APP读到损坏的ODEX直接崩溃。
  
  你每次"用RE管理器重新安装"之所以有效，是因为安装过程
  会重新生成ODEX缓存。

【解决思路】
  让车机每次开机自动做一次"覆盖安装"（pm install -r），
  相当于系统替你做了RE管理器安装的操作。

====================================
文件清单（最终方案文件夹内）
====================================

  autokit_onboot.sh  - 开机时自动执行的脚本（清缓存+覆盖安装+启动）
  deploy_v2.sh       - 一次性部署工具（把自动启动写入系统）
  手动一键修复.sh     - 手动修复用（不想等自动启动时点这个）

====================================
操作步骤
====================================

第一步：把文件复制到车机
   1. 准备U盘，将以下3个文件复制到U盘根目录：
      - AutoKit_2022.11.15.1535.apk （在"车机软件包"文件夹中）
      - autokit_onboot.sh
      - deploy_v2.sh
   
   2. U盘插车机，用RE管理器：
      把U盘中的3个文件全部复制到 /sdcard/ 根目录

第二步：执行部署
   1. RE管理器 → 进入 /sdcard/
   2. 长按 deploy_v2.sh → 选择"以脚本执行"（或"Execute"）
      注意：需要授予Root权限（弹框点允许）
   3. 等待看到"部署完成"提示
   4. 此时AutoKit应该已经自动打开了

第三步：验证
   1. 正常使用CarPlay 
   2. 关闭车机（彻底断电也行）
   3. 重新上车开机
   4. 等待约15-20秒，AutoKit应自动打开
   5. 如果没有自动打开，使用"手动一键修复.sh"

====================================
说明
====================================

● /sdcard/ 下的 AutoKit_2022.11.15.1535.apk 文件不要删除！
  它是每次开机自动安装的源文件。

● 如果想换AutoKit版本，替换 /sdcard/ 下的APK文件，
  同时修改 autokit_onboot.sh 中的文件名。

● 查看运行日志（排查问题）：
  用RE管理器打开 /data/local/tmp/autokit.log

● 如果部署成功但开机没自动执行：
  说明你的车机系统不走 install-recovery.sh 启动钩子。
  这时需要改用"手动一键修复.sh"：
  每次上车 → 打开RE管理器 → /sdcard/手动一键修复.sh → 执行
  （比重新安装APK快很多，3秒完成）

● 如需卸载自动修复：
  RE管理器 → 挂载/system为读写 → 
  删除 /system/etc/install-recovery.sh →
  重新挂载/system为只读
